# Introduction

**Vacui VQ** represents a multitasking operating system for 32-bit processors and hardware. The
ultimate goal of Vacui is to establish compatibility layers with various programming interfaces
and standards without breaking native VQ programs.

The project's codename is VQ that stands for **Vacui Quarter**.
