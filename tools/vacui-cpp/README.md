# `vacui-cpp`

`vacui-cpp` is a build system specifically made for Vacui. It is responsible for compiling,
linking/archiving and packing operating system components. `vacuicpp` is used only for C/C++ packages.

# Documentation

The `vacui-cpp`'s documentation is available in the `docs/tools/vacui-cpp` folder of the repository:
https://github.com/dywoq/vacui/tree/master/docs/tools/vacui-cpp.
