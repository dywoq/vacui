_______________________________________________________________________________

                                Development

Before writing an operating system code, you must ensure you have installed 
necessary tools and set development environment up in the project.

_______________________________________________________________________________

                            Required OS and tools

-   Linux: You can use any distribution that supports downloading subsequent 
    tools with specified version. Or, if you are on Windows, you can use 
    WSL (Windows Subsystem for Linux) 2.

-   GNU: Minimal version is 16.2. It must support compilation to x86 
    architecture.

-   GNU Make: Minimal version is 4.4.0.

-   Golang: Minimal version is 1.26

_______________________________________________________________________________

                    Setting the development environment up

This process is handled by a bash script "scripts/setupdevenv.sh" that 
compiles development tools and installs them to the ".devenv" folder. Then, it 
puts the folder onto the PATH environment variable. You should run the script 
from the repository root folder:

    source scripts/setupdevenv.sh

_______________________________________________________________________________

                        Environment variables

Environment variables are used to prevent usage of relative paths. The 
"scripts/setupdevenv.sh" script exports the following environment variables:

-   VACUI_BASE: A path to the "base/" folder.
-   VACUI_TOOLCHAINS: A path to the "toolchains/" folder. 
-   VACUI_TEMPLATES: A path to the "templates/" folder.
