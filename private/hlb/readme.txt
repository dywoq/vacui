                                HLB

The HLB (High-level BIOS) is a collection of libraries providing 
functionality, which wraps around BIOS services interrupts. It is preferred
over inline assembly code inserts.

______________________________________________________________________________

                            Navigation

    - Directory vid/ provides wrappers around BIOS video services functions.
